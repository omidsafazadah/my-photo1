# Simple Photo QR Website

This website does exactly one thing: it shows one image.

## Files
- index.html — displays the image
- photo.jpg — sample image
- QR-code.png — QR code for the site address

## Important
The included QR code uses this placeholder:

https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

After creating your GitHub Pages site, generate a new QR code for your real site URL.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `photo.jpg`.
3. Enable GitHub Pages from Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Your site will show only the photo.
6. Create a QR code for the final site URL.

To replace the image, simply replace `photo.jpg` with your own image and keep the filename `photo.jpg`.
